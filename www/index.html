A static site generator platform for Roc

Turn typed Roc programs into fast, straightforward websites.

Discover content, decode your own formats, render Markdown or AsciiDoc, compose typed HTML, and write the finished site—with one small platform.

Build your first siteBrowse main API docs
app [main!] { pf: platform "…/basic-ssg.tar.zst" }

import pf.SSG

pages = SSG.markdown_pages!(input_dir)?
html = SSG.parse_markdown!(page.source_path)?

Portable builds

Getting started

From content folder to website

  1. 1

    Choose a release

    Copy the platform URL from the latest GitHub release into your Roc app header.

  2. 2

    Discover and render pages

    Use SSG.markdown_pages! for Markdown, SSG.asciidoc_pages! for AsciiDoc, or SSG.pages_with! for another extension.

  3. 3

    Compose typed HTML

    Build a document with Html, insert trusted rendered fragments where needed, and write it with SSG.write_file!.
